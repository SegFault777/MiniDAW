## 배운 점
- 계층을 가르고 **Linux에서 테스트되는 부분을 최대한 넓히자** 빌드 실패의 대부분이 Windows 전용 파일의 `include`와 매크로 문제로 좁혀졌다.
- 화면도 메모리 속 픽셀로 그리면 **창 없이 테스트하고 스크린샷으로 눈으로 확인**할 수 있다.
- 번역을 "그릴 때 조회"로 하니 새 화면에 번역 코드를 따로 쓸 필요가 없어졌다.
