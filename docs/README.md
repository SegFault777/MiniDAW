# MiniDAW documentation

| Folder | Audience | Contents |
| --- | --- | --- |
| [`user/`](user/README.md) | Users | Installation, getting started, the screens, recording, editing, mixing, plug-ins, shortcuts, troubleshooting, the Vulkan interface |
| [`dev/`](dev/README.md) | Developers | Architecture, building, testing, UI toolkits, plug-in hosting, how to add a feature, coding rules |
| [`project/`](project/README.md) | Project management | Overview, roadmap, UI design comparison of five DAWs, release process, history, licences and credits |

All documents are written in English. The change log is `CHANGELOG.md` in the repository root; a short introduction is in the root `README.md`.
The installer ships `docs/user/` together with the program.
