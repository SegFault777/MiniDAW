# 문제 해결

## 소리가 나지 않아요
1. 상태 표시줄 오른쪽에 오디오 장치 이름이 보이나요? "No audio output"이면 **Preferences > Output device**에서 장치를 고르세요.
2. 마스터 레벨 미터(맨 위 오른쪽, OUT)가 움직이나요? 움직이면 프로그램은 소리를 내고 있는 것이므로 윈도우 볼륨과 스피커를 확인하세요.
3. 트랙에 **M**(음소거)이 켜져 있거나, 다른 트랙에 **S**(솔로)가 켜져 있지 않은지 보세요.
4. Software Instrument 트랙에 **악기**가 있는지 인스펙터에서 확인하세요.

## 소리가 끊기거나 지직거려요
**Preferences > Buffer size**를 한 단계 키워 보세요(예: 2048 → 4096). 다른 무거운 프로그램을 끄거나
플러그인을 줄이는 것도 도움이 됩니다.

## "Audio device lost"가 나왔어요
오디오 장치를 뽑거나 윈도우가 장치를 바꾼 경우입니다. MiniDAW를 다시 시작하세요.

## 녹음이 안 돼요 / 소리가 너무 늦게 들어가요
- 트랙의 **R**이 켜져 있어야 합니다. ("Arm a track with the R button first.")
- 마이크가 윈도우 설정 > 개인 정보 > 마이크에서 막혀 있지 않은지 확인하세요.
- 늦게 들어간다면 **Recording latency compensation**을 조절합니다.

## 파일을 열 수 없어요 / 가져올 수 없어요
- WAV, MP3, AAC/M4A, FLAC, WMA는 열립니다. OGG는 Windows 기본 코덱으로는 열리지 않을 수 있습니다.
- 프로젝트 파일은 `.mdaw`입니다.

## 프로그램이 이상하게 종료됐어요
다시 실행하면 자동 저장된 프로젝트를 복구할지 묻습니다. 복구한 뒤에는 반드시 저장하세요.
문제가 반복되면 `%LOCALAPPDATA%\MiniDAW\native-settings.ini`를 지우고(설정이 초기화됩니다) 다시 시도하세요.

## 글자가 흐릿하거나 너무 작아요
이 버전은 윈도우의 화면 배율에 맞춰 화면을 늘려 보여 주므로 고해상도 화면에서는 약간 흐릿할 수 있습니다.
창을 크게 열면 더 많은 내용이 보입니다.

## 신고하기
버그나 제안은 GitHub 이슈로 알려 주세요. 사용 중인 버전(`About MiniDAW`), 하려던 일, 나타난 메시지를 함께 적어 주시면 큰 도움이 됩니다.
