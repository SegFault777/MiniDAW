# 단축키

`Ctrl`은 Control, 소문자 표시는 글자 키입니다. **음악 타이핑**을 켜면 글자 키는 연주가 우선합니다.

## 재생과 녹음
| 키 | 동작 |
| --- | --- |
| `Space` | 재생 / 일시정지 |
| `Enter`, `Home` | 처음으로 |
| `R` | 녹음 시작/끝 |
| `C` | 사이클 켜기/끄기 |
| `K` | 메트로놈 |
| `T` | 탭 템포 |
| `←` `→` | 한 마디 뒤로/앞으로 (`Shift`와 함께면 한 박) |
| `[` `]` | 이전/다음 마커 |
| `M` | 현재 위치에 마커 추가 |

## 파일
| 키 | 동작 |
| --- | --- |
| `Ctrl+N` / `Ctrl+O` | 새 프로젝트 / 열기 |
| `Ctrl+S` / `Ctrl+Shift+S` | 저장 / 다른 이름으로 저장 |
| `Ctrl+I` | 오디오 가져오기 |
| `Ctrl+B` | WAV로 바운스 |
| `Ctrl+,` | 환경설정 |

## 편집
| 키 | 동작 |
| --- | --- |
| `Ctrl+Z` | 되돌리기 |
| `Ctrl+Shift+Z`, `Ctrl+Y` | 다시 하기 |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 리전 잘라내기 / 복사 / 붙이기 |
| `Ctrl+D` | 복제 |
| `Ctrl+T` | 재생 헤드에서 자르기 |
| `Ctrl+M` | 리전 음소거 |
| `Delete`, `Backspace` | 삭제 |
| `F2` | 이름 바꾸기 (리전 또는 트랙) |
| `↑` `↓` | 이전/다음 트랙 선택 |

## 화면
| 키 | 동작 |
| --- | --- |
| `X` | 아래 패널 보이기/숨기기 |
| `P` | Piano Roll 탭 |
| `I` | Inspector 탭 |
| `L` | 브라우저 보이기/숨기기 |
| `+` `-` | 확대 / 축소 (또는 `Ctrl`+휠) |
| `Esc` | 메뉴/대화상자 닫기, 선택 해제 |

## 피아노 롤 (Piano Roll 탭이 열려 있을 때)
| 키 | 동작 |
| --- | --- |
| `Ctrl+A` | 모든 노트 선택 |
| `Shift`+클릭 | 노트 선택에 추가/제거 |
| `Shift`+빈 곳 드래그 | 사각형 선택 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 노트 복사 / 잘라내기 / 재생 헤드에 붙이기 |
| `Ctrl+D` | 선택한 노트를 바로 뒤에 복제 |
| `Delete` | 선택한 노트 삭제 |

## 음악 타이핑 (View 메뉴에서 켜기)
`A W S E D F T G Y H U J K` → 도 도# 레 레# 미 파 파# 솔 솔# 라 라# 시 도. `Z` `X`는 옥타브.

## 마우스
| 동작 | 결과 |
| --- | --- |
| 눈금자 `Shift`+드래그 | 사이클 범위 정하기 |
| `Ctrl`+휠 | 가로 확대/축소 |
| `Shift`+휠 | 가로 스크롤 |
| 노브 `Shift`+드래그 | 미세 조절 |
| 더블클릭 (노브, 볼륨, 팬) | 기본값으로 |
