# Quick start (English)

1. **Install** `MiniDAW-<version>-setup.exe` (or unzip the portable build) and start MiniDAW.
2. **Add a track**: toolbar `+ Add Track` -> Audio, Software Instrument, Drum Machine or Drummer.
3. **Make a region**: double-click an empty part of an instrument or Drummer lane (4 bars). Double-click the
   region to edit it: instrument regions open the **Piano Roll**, Drummer regions the **Drummer** editor.
4. **Add loops, instruments and effects** from the **Browser** on the right: click to audition, double-click
   or drag onto a track.
5. **Record**: press `R` on an audio track header to arm it, then the record button (or `R`).
6. **Mix**: Mixer, Inspector and Devices tabs; automation and tempo in the Automation tab.
7. **Save** with `Ctrl+S`, **bounce** to WAV with `Ctrl+B`.

Hover any control: the status bar tells you what it does. Full manual (Korean): [README.md](README.md).
Shortcuts are listed in [shortcuts.md](shortcuts.md). The interface language follows Windows
(English, Korean, Japanese, Chinese, Spanish) and can be changed in `Preferences`.
