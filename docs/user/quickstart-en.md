# Quick start

1. **Install** `MiniDAW-<version>-setup.exe` (or unzip a portable build) and start `MiniDAW.exe` (Native) or `MiniDAWVulkan.exe` (Vulkan).
2. **Add a track**: `+ Add Track` -> Audio, Software Instrument, Drum Machine or Drummer.
3. **Make a region**: double-click an empty part of an instrument or Drummer lane (4 bars). Double-click the region to edit it: instrument regions open the **Piano Roll**, Drummer regions the **Drummer** editor (Native) or the notes (Vulkan).
4. **Add loops, instruments and effects** from the **Browser**: click to audition, double-click or drag onto a track.
5. **Record**: arm an audio track with `R` on its header, then press the record button (or `R`).
6. **Mix**: Mixer, Inspector and Devices; automation and tempo in the Automation tab; mixer snapshots in the Vulkan version.
7. **Save** with `Ctrl+S`, **bounce** to WAV with `Ctrl+B`.

Hover any control: the status bar tells you what it does. In the Vulkan version press `Ctrl+K` to search every command and `F1` for the shortcut sheet.
The interface language follows Windows (English, Korean, Japanese, Chinese, Spanish) and can be changed in Preferences.
